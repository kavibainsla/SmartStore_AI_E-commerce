# SmartStore AI — Backend API

Express + MongoDB + JWT + OpenAI integration.

## Setup

```bash
npm install
cp .env.example .env
npm run seed
npm run dev
```

API runs at `http://localhost:5000`

## Environment

See `.env.example` for all variables.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start with file watch |
| `npm start` | Production start |
| `npm run seed` | Seed demo user + products |
